Implementation notes

  • Both dialogs go at the end of <body> in apps.html, before #toast (same place as index.html #dlg-del). Add ask to the app.js import in apps.js.
  • Discard: in closeDrawer() replace the confirm with if (dirty() && await ask($('#dlg-discard')) !== 'ok') return false;. It opens with showModal(), so it sits in the top layer above the drawer (z-index 30) and its scrim.
  • Disable: set $('#dis-name').textContent = D.app.name (textContent, never innerHTML: the name is user-editable), then if (await ask($('#dlg-disable')) !== 'ok') return;.
  • Escape: the document keydown handler (apps.js:146) also sees the Escape that closes the lightbox, because keydown bubbles to document before the dialog closes. Without a guard it calls closeDrawer() again while the lightbox is open. Add a first line to that handler: if (document.querySelector('dialog[open]')) return;. The dialog then handles Escape alone (returnValue '' → cancel).
  • Focus: Cancel has autofocus, so showModal() focuses it; Enter/Space never fires Discard/Disable by accident. When the dialog closes, the browser returns focus to the drawer control that opened it.
